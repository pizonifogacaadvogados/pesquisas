# E11: Algoritmos e engajamento, Instagram e TikTok (2026)

> Base: registro R05. Os pesos exatos não são públicos. O que segue é o consenso entre declarações oficiais (Mosseri, TikTok) e análises de mercado, com o grau de confiança indicado.

## 1. O que cada plataforma recompensa

| | Instagram Reels | TikTok |
|---|---|---|
| **Sinais centrais** | tempo assistido; curtidas por alcance; **envios por DM por alcance** (Mosseri, 2025-2026) | tempo assistido, **conclusão**, **reexibição**, compartilhamentos, salvamentos, comentários |
| **Para crescer além dos seguidores** | **envios** (o conteúdo que a pessoa manda para alguém) | conclusão + compartilhamento no teste a frio |
| **Seguidores importam?** | sim, para a distribuição inicial | pouco: todo vídeo é testado a frio |
| **Duração recomendada a não seguidores** | **até 3 min** (acima disso, não recomenda) | livre; monetização (Creator Rewards) só **acima de 60s** |
| **Faixa de melhor desempenho (estimativa)** | 45-60s (marcas, 2026) | 21-34s para engajamento; 60-90s para monetizar |
| **Originalidade** | desde 30/04/2026, contas de conteúdo não transformado deixam de ser recomendadas | conteúdo reutilizado sem acréscimo fica fora do For You; marca d'água de outra plataforma idem |
| **Busca** | palavras-chave na legenda (não nos comentários); **máx. 5 hashtags** (dez/2025) | legenda + texto na tela + **transcrição automática do áudio** indexados |
| **Som** | ~50% dos Reels vistos sem som | maioria **com som** (80%+) |
| **Métrica-chave nos Insights** | **taxa de pulo** (saída nos 3 primeiros segundos), retenção, envios | retenção (gráfico), conclusão, origem do tráfego (For You, busca) |
| **Teste** | **Trial Reels** (só para não seguidores): testar 2-3 ganchos | publicar variações (não há trial nativo equivalente) |

## 2. Implicações diretas para a edição (o sistema aplica)

1. **Os primeiros 3 segundos decidem a taxa de pulo.** O 1º quadro precisa ter rosto + texto do gancho + movimento já começando. Nada de logo, vinheta de abertura ou "oi, gente".
2. **Feito para ser enviado:** o maior sinal de alcance no Instagram são os envios. Conteúdo "envie para quem precisa saber" (direito do consumidor, trabalho, golpes) é naturalmente compartilhável, e o CTA pode pedir isso explicitamente ("manda para aquele amigo que…").
3. **Loop:** terminar com uma frase que conecta ao começo gera reexibição, sinal forte nas duas redes.
4. **Legenda sempre:** obrigatória para o Instagram (metade sem som); no TikTok, a legenda e o texto na tela entram na **busca**. Então o texto na tela deve conter a **palavra-chave** do tema ("direito de arrependimento", "demissão por justa causa").
5. **Duração por objetivo:** alcance (Instagram 30-60s; TikTok 20-35s); autoridade/monetização (TikTok 61-90s). O sistema permite `--dur` por plataforma.
6. **Originalidade:** react e cortes precisam de transformação real (ver E10). Nunca exportar com marca d'água de outra rede. Exportar do CapCut **sem** marca d'água (o CapCut grátis pode inserir o final com logo; remova).
7. **Zonas seguras (1080×1920):** conteúdo crítico em ~900×1400 centralizado; base ~310-340px livre (legenda da rede); direita ~120-180px livre (botões); topo ~210px livre.
8. **Capa:** a grade do perfil corta em 3:4 (1080×1440 central). A capa precisa de título legível nesse recorte.
9. **Legenda do post (texto):** primeira linha = gancho + palavra-chave; até 5 hashtags específicas; no TikTok, 2-4 palavras-chave naturais.

## 3. Contexto Brasil (2026)

- Instagram ~145 mi, TikTok ~131-134 mi, YouTube ~150 mi, WhatsApp ~147-169 mi, **Kwai ~60 mi** (classes C/D, interior: relevante para política).
- O TikTok tem o maior tempo de uso por pessoa (~28h/mês, estimativa).
- **Política:** o vídeo nasce no Instagram/TikTok e **se espalha pelo WhatsApp**, então o arquivo final precisa funcionar comprimido (texto grande, áudio claro) e sem depender de recurso nativo da rede.
- Engajamento mediano de "jurídico/serviços profissionais" no TikTok é baixo (~0,9%); educação lidera (~7,4%). **Posicionar o conteúdo jurídico como educação**, não como serviço.

## 4. Fluxo de publicação recomendado

1. Exportar 1080×1920, 30fps, H.264, alta qualidade, sem marca d'água.
2. Instagram: capa personalizada (título no centro 3:4), legenda com palavra-chave, ≤ 5 hashtags, **Trial Reel** para testar o gancho quando houver dúvida.
3. TikTok: legenda com palavras-chave, texto na tela com o termo de busca, som original.
4. 24-48h depois: ler a **taxa de pulo** (Instagram) e o **gráfico de retenção** (TikTok) → o sistema registra o que funcionou para ajustar os próximos ganchos.
