## Como publicar (manual: o sistema não posta por você)
- **instagram**: App → + → Reel/Post → selecione o arquivo → cole a legenda → capa: 'Adicionar da galeria' (capa_reels.png) → Configurações avançadas: 'Enviar na qualidade mais alta' ligado → Compartilhar. Teste de gancho: 'Trial Reel'.
- **linkedin**: Começar publicação → Vídeo ou Documento (PDF do carrossel, dê um título) → texto → Publicar.
- **tiktok**: App → + → Carregar → arquivo → legenda (até 5 hashtags) → capa: selecionar quadro → 'Permitir uploads em alta qualidade' ligado → Publicar. Sem marca d'água de outra rede.
- **youtube**: YouTube Studio/app → Criar → Shorts (vertical ≤ 3 min) ou Vídeo → título + descrição → miniatura (thumbnail.jpg, só vídeo longo) → Público.
