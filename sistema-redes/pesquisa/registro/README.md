# Registro de pesquisa: Videomaker Viral

Diário de **todas** as pesquisas feitas para o projeto: o que foi buscado, onde, o que foi encontrado, quão confiável é e onde foi usado. É a fonte do relatório final.

## Método

- **Cada entrada** tem: ID, data, ferramenta (busca padrão/estendida, leitura de página), consulta exata, fontes (links), achados, confiabilidade e destino (em qual estudo ou código foi usado).
- **Escala de confiabilidade:**
  - **A**: fonte oficial ou primária (norma, documentação da plataforma, órgão público, artigo científico).
  - **B**: imprensa especializada ou profissional reconhecido.
  - **C**: blog, tutorial ou guia de fornecedor; útil, mas não verificado.
  - **D**: fonte fraca (SEO, spam, sem autoria); registrada só para rastreabilidade, **não usada** como base.
- **Lacunas:** quando a pesquisa não encontrou resposta, isso também é registrado. Lacuna também é achado.
- **Limitação do ambiente:** este servidor não acessa Instagram, TikTok, CapCut, TSE, OAB e vários blogs (bloqueio de rede). Por isso, várias leituras foram feitas via mecanismo de busca (resumo dos resultados), e não pela página completa. Isso aparece como "via busca" na ferramenta.
