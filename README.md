## Sistema de redes sociais (`sistema-redes/`)
Sistema de produção e gestão de conteúdo para redes sociais (advocacia, conteúdo jurídico e política), operado pelo Claude:
dois braços de produção — **vídeo** (Reels, TikTok, Shorts, YouTube, Kwai, Facebook, LinkedIn, X, Threads, Pinterest,
WhatsApp) e **foto** (carrosséis, posts, stories, capas, thumbnails) — sobre uma camada de **gestão** (perfis, pautas,
calendário, conformidade OAB/TSE/LGPD, pacote de publicação, métricas e aprendizado).
